# Regras e Diretrizes do Projeto RZ-Produtos

## 1. Controle de Versão (Git)
- **Automação de Commits:** Sempre que alguma alteração for realizada, testada e confirmada (conclusão de uma tarefa/etapa), o assistente **DEVE** automaticamente fazer o git add . e git commit detalhando o que foi feito.
- **Repositório Remoto:** As alterações devem ser commitadas no repositório.

## 2. Padrões de Código
- O código deve ser sempre **100% limpo, legível e otimizado**.
- Evitar redundâncias, seguir as convenções de tipagem do TypeScript rigorosamente.
- Código não utilizado deve ser removido.
